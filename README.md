# Exl-Design Next.js

This version recreates the Framer site structure and responsive design system without final project images.

## Run
npm install
npm run dev

Open http://localhost:3000

## Replace images
Search the project for `MediaPlaceholder`. Replace each placeholder with your own `<img>`, Next `<Image>`, or `<video>` element.
